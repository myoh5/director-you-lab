요즘 떡상 제목의 조합 공식

떡상 제목은 화려한 미사여구가 아니라 아래 요소 2~3개의 조합입니다. 전부 욱여넣으면 스팸처럼 보이니, 아래 분석기로 조합 개수를 확인하며 다듬으세요.

공식 A · [타겟] + [숫자 결과] + [단서 감추기]
예: "초보도 30m 느는 단 하나의 연습법" — "초보도"가 내 얘기로 만들어 멈추게 하고, "30m"가 결과를 약속하고, "단 하나"가 방법을 감춰 클릭 전에는 답을 못 얻게 합니다. 가장 안정적인 정보형 공식.
공식 B · [상식 뒤집기·경고] + [이유 예고]
예: "드라이버 연습부터 하면 안 되는 이유" — 손실 회피 심리를 씁니다. 사람은 얻는 것보다 잃는 것에 2배 민감해서, "내가 지금 잘못하고 있나?"라는 불안은 무시하기 어렵습니다.
공식 C · [대결·비교] + [결말 감추기]
예: "프로 vs 아마추어 100만원 내기, 결과가…" — 대결 구도는 승부 확인 욕구를 만들고, 말줄임표·"결과가"류 표현이 결말을 감춥니다. 댓글 논쟁까지 유발해 참여도도 함께 올라갑니다.

📺 내 채널 연동

📖 DIRECTOR YOU LAB 가이드

1. 시작하기

이 앱은 구글 공식 YouTube Data API를 내 API 키로 직접 호출하는 개인용 분석 도구입니다. 우측 상단 ⚙️에서 키를 등록하면 모든 기능이 열립니다. 하루 무료 한도는 10,000유닛(키워드 검색 약 95회)이고 한국시간 오후 4~5시경 자동 초기화됩니다.

2. 영상 찾기

키워드로 영상을 검색하고 떡상 영상(채널 규모 대비 조회수가 터진 영상)을 골라내는 핵심 기능입니다. 정렬·기간·길이(쇼츠/미드폼/롱폼)·지역 필터를 조합하고, 열 제목을 클릭해 정렬하세요. 마음에 드는 영상은 체크 후 영상 수집으로 보관함에 저장합니다. 검색하면 하단에 아이디어 확장 키워드(유튜브 자동완성 기반)가 함께 표시됩니다.

3. 지표 해석 방법

4. 채널 찾기 · 채널 분석

채널 찾기에서 주제로 채널을 검색하면 구독전환·영상성과·성장속도를 한눈에 비교할 수 있습니다. 📊 분석을 누르면 채널 분석 탭에서 최근 50개 영상의 성과, 업로드 주기, 평균 좋아요까지 상세 분석됩니다. 분석한 채널은 등록 채널 칩으로 저장되어 클릭 한 번으로 최신화할 수 있습니다.

5. 수집한 영상 (보관함)

검색 결과에서 체크해 수집하거나, 영상 URL을 직접 붙여넣어 수집할 수 있습니다. 폴더를 만들어 주제별로 정리하고(예: 골프레슨/쇼츠아이디어), 전체를 CSV로 내보내 스프레드시트에서 활용하세요. 데이터는 이 브라우저에 저장되어 껐다 켜도 유지됩니다.

6. 자주 묻는 질문

  • 검색이 안 돼요 — ⚙️ 설정에서 키 테스트를 눌러보세요. "API 활성화" 오류면 Google Cloud Console에서 YouTube Data API v3 사용 설정이 필요합니다.
  • 한도를 다 썼어요 — 검색 1회 = 약 102유닛입니다. 매일 초기화되니 내일 다시 이용하거나, 채널 분석(약 4유닛) 위주로 사용하세요.
  • 지속 시청시간(시청 지속률)도 볼 수 있나요? — 시청시간·지속률·노출 클릭률은 유튜브가 채널 소유자에게만(YouTube Studio) 공개하는 비공개 데이터라, 다른 채널의 것은 어떤 외부 도구로도 볼 수 없습니다. 공개 데이터로 계산 가능한 가장 가까운 대체 지표가 참여도(좋아요+댓글 ÷ 조회수)입니다. 내 채널의 시청시간 분석이 필요하면 말씀해 주세요 — 채널 소유자 인증(OAuth) 방식으로 별도 제작이 가능합니다.
  • 성장 그래프는 실측인가요? — 수집한 영상은 앱이 열려 있는 동안 1시간마다 조회수를 자동 기록하고, 상세 창을 연 영상도 열 때마다 기록됩니다. 기록이 2회 이상 쌓이면 그래프가 추정 곡선(점선)에서 실측 곡선(실선)으로 바뀝니다. 서버 없이 브라우저가 기록하는 방식이라 앱을 꺼둔 시간에는 기록이 쌓이지 않는 점만 참고하세요. 24시간 무인 기록은 서버 배포 버전에서 가능합니다.
  • 구독자가 '비공개'로 나와요 — 해당 채널이 구독자 수를 숨긴 경우로, 성과도 등급은 계산되지 않습니다.
  • 다른 컴퓨터나 새 버전 파일로 옮기고 싶어요 — 마이페이지 → 데이터 백업(내보내기)으로 JSON 파일을 저장한 뒤, 새 파일/새 컴퓨터에서 데이터 복원(불러오기)하면 API 키·수집 영상·기록이 전부 이어집니다.
