# DIRECTOR YOU LAB 🎬

**유튜브 트렌드 분석 도구** — 떡상 영상과 성장 채널을 지표로 찾아내는 오픈소스 웹앱

라이브 데모: https://myoh5.github.io/director-you-lab/

## 소개

서버 없이 **HTML 파일 하나**로 동작하는 유튜브 분석 도구입니다. 사용자가 본인의 무료 YouTube Data API 키를 등록하면, 브라우저가 구글 API를 직접 호출해 영상·채널 성과를 분석합니다. 서버 비용 0원, 회원가입 불필요, 데이터는 사용자 브라우저(및 선택 시 본인 GitHub Gist)에만 저장됩니다.

## 주요 기능

- **영상 찾기** — 키워드 검색 + 기여도·성과도·노출확률(추정)·일평균 조회수 등급 분석, 세부 필터(조회수·구독자·좋아요 범위, 게시일, 등급별, Shorts), 썸네일 갤러리 모드, 제목 공식 분석
- **🔥 떡상 레이더** — 검색어 없이 카테고리 클릭만으로 유튜브 실시간 인기 급상승(14개 카테고리)과 주제별 최근 7일 떡상 영상(16개 주제) 탐색
- **✍️ 제작 가이드** — 제목 후보 입력 시 예상 성과 채점(0~100점), 떡상 제목 조합 공식 A·B·C, 썸네일 자가진단 10항목, 썸네일 픽셀 자동 측정(대비·색·밝기·단순함), 실제 떡상 썸네일 벤치마킹·분석 연습 모드, A/B 테스트 3안 콘셉트 제안
- **📺 내 채널** — @핸들 등록만으로 채널 진단: 쇼츠 vs 롱폼 성과, 업로드 요일별 평균 조회수, 내 제목의 떡상 공식 사용률, 베스트/아쉬운 영상
- **채널 찾기/분석** — 구독전환·영상성과·성장속도 등급, 분석 결과 저장(재조회 시 사용량 차감 없음), 등록 채널 즐겨찾기
- **영상 상세** — 베스트 댓글, 해시태그, 채널 정보, 인기 영상, 조회수 성장 그래프(수집 영상은 1시간 단위 실측 기록)
- **수집한 영상** — 폴더 정리, URL 직접 수집, CSV 내보내기, 조회수 자동 추적
- **☁️ 기기 간 자동 동기화** — GitHub 비공개 Gist를 개인 클라우드로 사용해 모든 기기에서 데이터 자동 연동
- 데이터 백업/복원(JSON), 다크/라이트 테마, 사용량(쿼터) 자동 집계, 검색 전 확인창

## 사용 방법

1. `index.html`을 브라우저에서 열거나 GitHub Pages 등에 배포합니다
2. 앱 안내에 따라 [Google Cloud Console](https://console.cloud.google.com)에서 무료 YouTube Data API v3 키를 발급합니다 (약 3분)
3. 키를 등록하면 모든 기능이 열립니다 — 무료 한도는 하루 10,000유닛(키워드 검색 약 95회)

## 핵심 지표 공식

| 지표 | 공식 | 의미 |
|---|---|---|
| 기여도 | 조회수 ÷ 채널 평균 조회수 | 채널 안에서 이 영상이 효자인가 |
| 성과도 | 조회수 ÷ 구독자수 | 채널 체급 대비 얼마나 터졌나 |
| 노출 확률(추정) | 성과도+참여도+최신성 가중 합성 | 알고리즘 추천을 받고 있을 가능성 |
| 일평균 조회수 | 조회수 ÷ 게시 후 경과일 | 조회 속도 (신작·구작 공정 비교) |
| 조회수대비 구독전환 | 구독자 ÷ 총 조회수 | 시청자를 구독자로 바꾸는 힘 |
| 성장속도 | 구독자 ÷ 개설 후 개월수 | 월평균 구독자 증가 |

등급은 Great!! · Good · Normal · Bad · Worst 5단계이며, 임계값은 소스의 `computeMetrics` / `channelDerived` 함수에서 조정할 수 있습니다.

## 기술 스택

- 순수 HTML/CSS/JavaScript 단일 파일 (프레임워크·빌드 도구 없음)
- YouTube Data API v3 (사용자 본인 키, 브라우저 직접 호출)
- localStorage 저장 + GitHub Gist 동기화(선택)
- 차트·히스토그램은 인라인 SVG로 직접 렌더링
